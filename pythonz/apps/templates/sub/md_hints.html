Справка по форматированию

Тексты оформляются в разметке Markdown. Ниже описаны основные правила и особенности, свойственные pythonz.

Строки Перевод строки трактуется как начало новой строки. Пустая строка начинает новый абзац.
Ссылки Ссылки на внешние ресурсы, начинающиеся с http форматируются автоматически.
Можно скрыть ссылку под именем, используя следующий код.

Вставка ссылки [под именем](https://pythonz.net/).
Начертание Для выделения слова или фразы полужирным используйте обрамление в двойные звёзды.

Выделение **полужирным**.
Для выделения слова или фразы курсивом используйте обрамление в звёзды.

Выделение *курсивом*.
Акцентирование Слово или фразу можно акцентировать путём обрамления в апострофы.

Выделение `акцентом`.
Списки Маркированный список создаётся строками, начинающимися со звезды.

* Первый элемент.
* Второй элемент.
Подзаголовок Подзаголовок можно создать, начав строку с четырёх символов #.

#### Подзаголовок
Блок «На заметку» Блок можно выделить визуально при помощи разметки !!! note.
Текст заметки размещается на следующих строках с отступом.

!!! note
    Текст заметки.
Блок «Внимание» Блок можно выделить визуально при помощи разметки !!! warning.

!!! warning
    Текст предупреждения.
Таблицы Таблицы создаются при помощи разметки с вертикальными чертами. Первая строка станет заголовком, за ней следует строка-разделитель.

| заголовок | заголовок 2 | заголовок 3 |
|---|---|---|
| 1 | первый ряд | текст 1 |
| 2 | второй ряд | текст 2 |
Цитаты
Для оформления цитаты начните строки с символа >. 
> Это цитата.
Сноски Сноска оформляется меткой [^имя] в тексте и определением с тем же именем на отдельной строке.

Текст со сноской.[^1]

[^1]: Текст сноски.
Исходный код Подсветка синтаксиса реализуется путём выделения кода в блок, ограждённый тройными апострофами, с указанием имени языка.

Некий текст.

```python
def my_function():
    "just a test"
    print 8/2
```

И снова текст.
Упоминание языка не обязательно. Если он не указан, используется подсветка Python.
Изображения Изображение вставляется разметкой ![описание](url).

![Снимок экрана](https://pythonz.net/media/img.png)
Gist от GitHub Гисты (куски исходного кода) могут быть вставлены в текст при помощи блока ```gist с указанием гитхаб_логин/ид_гиста.

```gist
idlesign/c1255817bb0234d9971a
```
Гисты можно создавать по адресу https://gist.github.com/
Опрос от Яндекс.Форм Виджет опроса вставляется при помощи блока ```poll с указанием ид_опроса.

```poll
5cb46b0c19621d0212e32587
```
Видео YouTube Встроить проигрыватель можно при помощи блока ```video с указанием url_страницы_видео.

```video
https://youtu.be/ZE7WsnmGZ3U
```
Подкаст с podster.fm Встроить проигрыватель можно при помощи блока ```podcast с указанием url_страницы_подкаста.

```podcast
http://mtpod.podster.fm/5
```
